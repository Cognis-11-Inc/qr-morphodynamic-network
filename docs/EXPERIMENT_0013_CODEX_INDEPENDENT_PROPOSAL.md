# QR13 independent proposal: test observability before interpreting latent structure

## A. Observation

**VERIFIED FACT.** In `src/morphodynamic_0012.rs`, `Port::new` constructs a
finite-support pressure kernel from the body's position. Both module9 and27 ports
use that same position/kernel. `Port::rotate` couples a weighted shared-fluid
pressure projection to one mechanical velocity. `Neuron::acceleration` is linear
in u at fixed palette; damping is linear in v. `World::advance` composes these
with the linear acoustic map. Registered switches change coefficients and perform
external work; the complete system is a driven hybrid system, not an unexplained
nonlinear neural network between events. QR12 independent composition already
reproduced this map near roundoff. These are source/previous evidence facts,
not discoveries by the learner. The fixed-palette **mechanical/fluid subsystem**
is linear; bounded sensing/traces and the gated controller are nonlinear readout/
decision variables. The complete trace/controller state transition is not claimed
to be linear. This distinction matters when interpreting reduced physical modes.

**VERIFIED FACT.** The local packet has7 components, whereas the shared pressure
and velocity state has4*n^3 entries. The current QR13 global compact instrument
also omits almost all of that state. Its name "global" means an external view,
not a complete Markov state. Four bodies, a few historical seeds and a prescribed
pulse are not a broad excitation/identification study. Full fluid observations
exist only at sparse checkpoints, never every tick.

**VERIFIED FACT.** In QR13 development the chosen learner's validation loss does
not beat the strongest reduced baseline. The final tests are still reserved when
this proposal is written. This is a limitation of the present instrument/data,
not evidence that the authoritative physics is false.

## B. Scientific reasoning

**STRONG INFERENCE.** Some forecast residuals may arise from unobserved fluid
state, changing forcing regimes and limited excitation, rather than from a new
collective law. An encoder cannot generally recover an arbitrary fluid state
from one compact instantaneous sensor vector. Finite histories may help within
a restricted driven family; empirical generalization is still required.

The instantaneous continuous coupling from the two velocities to a single body's
fluid kernel is rank one. Two ports do not by themselves supply two independent
spatial channels. At finite split size, order matters: for one ascending half
word with angle a and c=cos(a),s=sin(a), the pressure projection becomes
x_after=c^2*x_before+c*s*v9+s*v27. A velocity direction proportional to(1,-c)
is invisible to that output row for that half word. This is an algebraic statement
about one split factor, NOT a proof of a permanently dark mode: intrinsic mixing,
reverse order and later fluid propagation can expose it. Different bodies have
different kernels. No claim that the full four-body network has rank-one dynamics.

**HYPOTHESIS.** Excitation-weighted observability/controllability, rather than raw
latent dimension or event count, may explain why some morphology changes have
large local and weak remote effects. Weak mode excitation, coupling geometry,
external switching work and inadequate time windows are alternative explanations.
No one of them is established by this argument.

## C. Falsifiable question

**HYPOTHESIS for a separately registered0014.** Two lawful prepared states with
identical compact local/global observer values, identical palettes/u/v and equal
fluid energy can have different future body responses because their unobserved
fluid pressure fields differ. No deterministic instantaneous reduced map of that
observer state can be exact over both states. This is a finite prepared-state
closure claim, not a claim against useful statistical forecasting on a restricted
distribution. It is motivated by known equations, not nominated as a new law.

## E. Falsification and ambiguity

The prepared-state claim fails for the chosen registered pair if complete observer
values match but future neural differences are absent within the specified valid
window despite a resolved full-fluid arrival at the ports. If initial observed
values differ, fields never arrive, numerical error dominates, energy differs or
P/F disagree, the experiment is INDETERMINATE and does not test closure cleanly.
A failure for one packet does not prove all compact observations are Markovian.
A successful pair demonstrates a closure limitation for that observer, not novel
acoustics, memory or consciousness.

The modal explanatory hypothesis fails if registered excitation-weighted measures
have no held-family predictive advantage over simpler amplitude/work/geometry
controls; weak correlation on the same trajectories is not confirmation.

## F. Expected scientific value

Success identifies which physical information a reduced instrument must retain
and prevents attributing missing-state errors to mysterious emergence. A negative
or inconclusive result still tests preparation/numerical contracts and exposes
measurement limits. The practical goal is reliable reduced closure/error bars,
not a decorative latent visualization or a needlessly complex learner.
